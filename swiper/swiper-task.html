我（提示词 1）
帮我用 Swiper 写一个轮播初始化配置：new Swiper('#wySw4', {...})，要求能自动播放，每 3.2 秒翻一页，带圆点分页器，初始切换效果是 cube。

new Swiper('#wySw4', {
  autoplay: { delay: 3200 },

02

creative 电影墙任务二 · 课堂没讲的第 7 种 effect，让 AI 教我读懂官方 demo

打开官方示例 swiper/demo/257-effect-creative.html 后，creativeEffect 里的 prev / next transform 写法看不懂，请 AI 讲解，并仿写"电影选片墙"效果，加到演示四的第 7 个按钮上。

💬 关键对话

我（提示词）
Swiper 有第 7 种 effect：creative。我看了官方 demo 257-effect-creative.html，里面 creativeEffect: { prev: { translate: [...], rotate: [...] }, next: {...} } 这种写法看不懂。我要做一个"电影选片墙"：上一张缩小左移并带一点角度，下一张放大右移，像站在电影海报墙前选片。请给我一版配置，并用大白话解释：prev 和 next 的 transform 各控制什么？translate 里的百分比相对谁？
AI（回答）
creativeEffect 是"自定义变换"效果：Swiper 会给每张 slide 算一个进度值（-1 ~ 1，表示它相对当前激活张的位置），然后把 prev / next 里定义的变换按进度插值。

prev 控制"正在退场的上一张"去哪儿；next 控制"即将进场的下一张"从哪儿来。

translate 的百分号相对该 slide 自身的尺寸（水平分量相对自身宽度，垂直分量相对自身高度），不是相对整个轮播容器；第三个数字是 Z 轴像素值，负值往屏幕里退、正值往屏幕外迎。rotate 的第三个值是 2D 旋转角（度）。

电影选片墙配置参考： 
creativeEffect: {
  limitProgress: 2,
  shadowPerProgress: true,
  prev: {
    translate: ['-85%', 0, -320],  // 左移 85%（相对自身宽）、向内退 320px
    rotate: [0, 0, -12],           // 左倾 12 度
    opacity: 0.55
  },
  next: {
    translate: ['85%', 0, 320],    // 从右侧 85% 进场、从外向内迎
    rotate: [0, 0, 12],            // 右倾 12 度
    opacity: 0.55
  }
}
注意 effect 要同时设为 'creative' 才会生效。
我（追问验证）
我照这版配置加到了页面的第 7 个按钮上，实测有效。再追问：如果我想让卡片转 20 度，改哪个数值？
AI（回答）
改 rotate 的第三个值即可：prev 的 rotate: [0, 0, -20]、next 的 rotate: [0, 0, 20]（一左一右对称）。改完刷新，两侧的海报倾角立刻变陡。

🧪 验证

点击第 7 个按钮「creative 电影墙」✅ 通过：上一张缩小左移左倾、下一张从右侧放大迎进，拖动时插值过渡自然；把 rotate 改成 20 后两侧卡片倾角明显变大 ✅。
一句话结论：creative 效果 = 自己定义"上一张的去向"和"下一张的来路"，Swiper 负责按进度插值。

🎤 答辩抽问 · 预答

Q：transform 里的百分号是相对谁的？
A：相对每个 slide 自身的尺寸——水平分量相对自身宽度，垂直分量相对自身高度，与容器无关。
Q：改一个数值让卡片转 20 度？
A：rotate 数组第三个值是 2D 旋转角（度），把 ±12 改成 ±20 即可，已在页面试过。

💬 关键对话 2：keyboard 键盘控制（AI 第一次答错了）

我（提示词）
我要给演示四的 #wySw4 加键盘控制：按 ← → 键能翻页。要求页面滚动到其它区域时按键不要误触发轮播。给我 keyboard 配置并解释参数。
AI（回答 1 —— 有错）
用 Keyboard 模块： 
import Swiper from 'swiper';
import { Keyboard } from 'swiper/modules';

new Swiper('#wySw4', {
  modules: [Keyboard],
  keyboard: { enabled: true }
});
enabled: true 开启方向键翻页。
我（追问 + 指错）
报错了：我页面是 <script src="swiper-bundle.min.js"> 这种全量打包引入，没有用 npm / ES Module。第一版代码里的 import 会直接报错吧？另外"滚动到别处不误触发"你还没解决。
AI（回答 2 —— 修正）
抱歉，我默认按 npm 工程的写法答了。你用的是 swiper-bundle 全量文件，所有模块已经内置，不需要 import、也不需要 modules 数组，直接写参数即可；"只在可视区域内响应"用 onlyInViewport: true： 
keyboard: {
  enabled: true,        // 开启 ← → 翻页
  onlyInViewport: true  // 轮播不在视口内时不响应按键
}
直接放进 new Swiper 的配置对象里就行。
🧪 验证：去掉 import / modules 后无报错；滚动到演示四可见时按 ← → 能翻页 ✅，滚到页面顶部时按方向键只滚动页面、轮播不动 ✅。
一句话结论：bundle 全量版 = 模块全内置，只写 keyboard 参数；AI 第一版错在按 npm 按需引入的语境作答，没先确认我的引入方式。

🎤 答辩四连 · 预答

Q1：这段代码什么意思？
A：keyboard.enabled: true 开启方向键控制；onlyInViewport: true 限制只有轮播在视口内才响应按键；它和原有 loop / autoplay 不冲突。
Q2：AI 第一次答的哪里不对？你改了什么？
A：AI 按 npm 工程写了 import { Keyboard } + modules: [Keyboard]，但我用的是 script 引入的全量 bundle，这套写法直接报错。改法：删掉 import 和 modules，只保留 keyboard 配置，并补上 onlyInViewport: true。
Q3：新参数的作用？
A：delay 3200 = 每张停留 3.2 秒；disableOnInteraction: false = 手动操作后不停止；keyboard.onlyInViewport = 防误触发；speed 800 = 翻页动画时长（与 delay 无关）。
Q4：现场把 delay 改成指定值并解释预期变化？
A：改成 delay: 1000 → 每张只停 1 秒，节奏明显变快；改成 delay: 8000 → 停 8 秒。delay 只管"停留多久"，动画快慢由 speed 控制。
