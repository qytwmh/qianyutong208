线条是
可以改的

Lucide 不打包字体，它给出的是一段段 SVG 代码。描边粗细、颜色、尺寸都能单独调整，代价是需要脚本或手工写进页面。这一页把 16 个线性图标放上制图台，可以直接动手改。

SVG 是代码，不是字形

每个图标都是一段独立的矢量代码，浏览器按路径直接绘制。所以描边、颜色、尺寸可以逐个图标调整，放大多少倍都不会糊，也不受字体加载失败的影响。

代价是它不像字体图标那样只写一个 class：要么用脚本批量注入，要么把代码直接贴进 HTML。页面里这 16 个图标，就是由本地 Lucide 脚本把占位元素替换成 SVG 得到的。

<svg viewBox="0 0 24 24" fill="none"
     stroke="currentColor"
     stroke-width="1.5"
     stroke-linecap="round">
  <path d="M19 14c1.49-1.46 3-3.21 3-5.5A5.5 5.5
           0 0 0 16.5 3c-1.76 0-3 .5-4.5 2
           -1.5-1.5-2.74-2-4.5-2A5.5 5.5 0 0 0 2
           8.5c0 2.3 1.5 4.05 3 5.5l7 7Z"/>
</svg>
