Font Awesome 6.7.2 · 字体图标

把图标
当成字来排

Font Awesome 把每个图标做成字体文件里的一个字形。换字号就是换尺寸，换颜色就是换墨色，和排一段文字没有区别。这一页用它本地的 solid 字体做标本。

它为什么长得像文字

图标没有自己的图片文件，它是字体里的一个编码。字体加载完成后，浏览器把它当作字符画出来，所以 CSS 的字号、颜色、描边都能直接作用在图标上。

代价是整套字体始终一起加载：这页的 solid 字体约 158 KB，哪怕只用到一个心形，整个字体文件也会被下载。图标也不能像 SVG 那样分区域上色。

<i class="fa-solid fa-heart"></i>

/* 尺寸与墨色都由字体控制 */
.wy_tile i {
  font-size: 38px;
  color: #2b3fa6;
}
